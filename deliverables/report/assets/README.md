# Report figure assets

The PNGs in this directory are byte-for-byte copies of the exports in `work/projects/assets/`. Portfolio, scenario and horizon figures were generated by `work/projects/portfolio_charts.ipynb`; the four new cash-flow table figures were generated by `work/projects/focus_financial_tables.ipynb`. Both notebooks read the existing workbook and make assumptions explicit. No PNG is authored directly by a language model. The source and scope of each figure are documented in `work/projects/portfolio_visuals.md`.

The bubble chart, horizon mixes, project curves and portfolio curve exclude the separate cost-of-inaction overlay. H3 long-term bubbles and the 15-year mix are speculative illustrations. The project and portfolio curves show cumulative undiscounted cash, not NPV. P13 is in EUR; other focus-case charts are in USD. Preserve captions, units, time frame and limitations in any DOCX conversion. If any chart is updated, regenerate it in the notebook or workbook, copy the new export here, and reconcile the report and note to its inputs.

The four `notebook_p*_cash_table.png` figures are generated from the workbook's cached base scenarios by `work/projects/focus_financial_tables.ipynb`, using Pillow inside the notebook. The notebook checks annual cash reconciliation and converts P13 values back to EUR using the workbook FX input. The original Excel workbook and existing Matplotlib charts remain unchanged. Each displayed number is rounded to three decimals; use the report's editable tables or the workbook for higher precision. To regenerate, run the notebook from within the repository with `openpyxl` and `Pillow`, then copy the exported figures here and check the result.
