# Livrables

`report/` contient le rapport de fond, `memo/` le mémo Comex de deux pages et `slides/` le support de soutenance. `archive/` reçoit une copie des versions effectivement envoyées au professeur le 10 novembre au soir. Tout chiffre partagé doit être identique dans les trois livrables ou accompagné d'une explication de périmètre.
