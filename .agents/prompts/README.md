# Prompts pour recherches externes

Copier le prompt correspondant dans Perplexity ou un autre outil de recherche, remplir les champs entre crochets et conserver la réponse dans `sources/synthesis/`. Les réponses ne deviennent utilisables qu'après vérification des documents originaux et inscription des sources dans `sources/register.md`. Ne pas demander à l'outil de confirmer une stratégie préchoisie.
